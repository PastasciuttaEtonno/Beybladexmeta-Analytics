## Descrizione (fonte esterna)

<!-- provenance: third-party | source: https://beyblade.wiki/1-70-ratchet/ | kind: description -->

First released with the UX-15 Shark Scale Deck Set as part of the Xtreme Gear Sports Basic Line system on August 9th, 2025, 1-70 (or One Seventy) is a Ratchet from the Beyblade X generation.

The number “ 1 ” refers to the number of protrusions along the Ratchet’s perimeter, which means that 1-70 has 1 large protrusion. In Beyblade X, Ratchets protrusions are usually acting as weak points for burst attacks. However, these protrusions can also act as secondary contact points, which is the case with One Seventy. This Ratchet can be aligned in two different positions on any Beyblade X Blade, therefore players may want to check both to see which one they like the most. Furthermore, 1-70 features the largest protrusion on any Ratchet, making it a preferred choice in attack type combinations, although it is used in various combinations types in Beyblade X official tournaments.
