## Descrizione (fonte esterna)

<!-- provenance: third-party | source: https://beyblade.wiki/4-50-ratchet/ | kind: description -->

First released in the UX-15 Shark Scale Deck Set as part of the Xtreme Gear Sports Unique Line system on August 9th, 2025, 4-50 (or Four Fifty) is a Ratchet from the Beyblade X generation. The number “ 4 ” refers to the number of “blades” or “protrusions” along the Ratchet’s perimeter, so 4-50 has four protrusions. In Beyblade X, Ratchets blades are acting as weak points for burst attacks, therefore players have to make sure the protrusions of the ratchet are not too exposed. The number “ 50 ” refers to the Ratchet height, which in this case is 5 mm. This height is the lowest in Beyblade X, meaning that this Ratchet can be used to strike most opposing Beyblades from below. This facilitate strikes on the opposing Beyblade Ratchet, thus increasing Burst attack potential. Furthermore, the “50” height Ratchets have weaker locks than the “60” height Ratchets. However, lower Ratchet are harder to strike, thus slightly increasing Burst Resistance. 4-50 having a slightly better Burst Resistance than its “60” variant, it could potentially find niche use when players want to create combinations sitting at the lowest possible height.
